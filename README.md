# Контур — мониторинг автомобильного завода

Три рабочих места диспетчеров, общая карта предприятия, движение транспорта,
датчики, журнал КПП и обработка происшествий на одном локальном сервере.
Данные демонстрационные (`demo=true`); система не управляет реальными воротами
или машинами и не прогнозирует столкновения.

**Версия v5 добавляет вход и регистрацию с подтверждением администратора,
базовую защиту API, проходы людей через КПП и сценарий «сначала люди, потом
транспорт».** Карта содержит 18 объектов, единую сеть дорог и зоны по допуску.
Правила, журнал и движение работают без ИИ. ML и локального агента подключают
Гриша и Гаджи отдельно; эта поставка не подтверждает их готовность.

## Запуск

Нужны Python 3.11+ и Git. Первую установку зависимостей выполните с интернетом;
после этого базовый продукт использует локальные скрипты, карту и SQLite.

```powershell
git clone https://github.com/Military05/Hackathon.git
cd Hackathon
git rev-parse HEAD
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
.\.venv\Scripts\python.exe scripts/manage_users.py create-admin
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

Откройте `http://127.0.0.1:8000`. CLI создания администратора спрашивает логин,
имя и пароль; пароль не передаётся в аргументах команд. Длина пароля — 15–128
символов. Готового пароля администратора нет. При повторном запуске уже
установленного проекта достаточно последней команды, аккаунты сохраняются.

Подробная инструкция с подтверждением заявок, тремя профилями браузера, сценариями и
проверками жюри: [PRODUCT_V5](docs/PRODUCT_V5.md).
Краткие команды и переменные: [RUNTIME_QUICKSTART](docs/RUNTIME_QUICKSTART.md).

## Три диспетчера и администратор

| Назначенный профиль | Основная область |
| --- | --- |
| dispatcher-1 | Логистика и склады |
| dispatcher-2 | Производство |
| dispatcher-3 | КПП, офис и сохранённые резервные функции координации |

Регистрация создаёт заявку `pending`. Администратор назначает профиль и
подтверждает доступ. Сервер берёт личность из сессии: изменение `?operator=…`
или `X-Demo-Operator` не переключает аккаунт. Администратор — отдельная роль;
четвёртый сектор не создаётся. Произвольные случаи чужого сектора нельзя принять
только благодаря номеру dispatcher-3: работают свой сектор, адресованная
эскалация и согласованная передача.

Для трёх разных аккаунтов на одном компьютере используйте разные профили
браузера либо разные браузеры. Обычные вкладки одного профиля разделяют cookie
входа. Один FastAPI worker и одна SQLite обслуживают все рабочие места.

## Что можно проверить

- Карта: «Мой сектор», «Весь план», короткие подписи внутри зданий, символы П/С.
- Зоны: красная штриховка запрещает весь транспорт; оранжевая — въезд по допуску.
  Секторы обозначены тонкими контурами без заливки; голубой заливки нет.
- Восемь сценариев движения: нормальная работа, логистика, начало смены,
  обслуживание, нарушение зоны, проход без допуска, потеря связи и одновременные
  происшествия. Встроенный источник передаёт настоящие Event, не анимацию клиента.
- Начало смены: U1/U2/U3 проходят КПП, затем начинают двигаться машины в том же
  эпизоде. Во время ожидания позиции и heartbeat остаются свежими.
- Поиск/фильтры КПП, время сигналов, принятая ответственность, реакция,
  передача, завершение и краткая сводка своих действий.
- CSV КПП — до 200 последних записей выбранного фильтра; CSV действий — до
  1000 последних собственных записей по умолчанию, API допускает максимум 2000.
- Минимальная админ-панель: подтверждение/блокировка аккаунтов, назначение сектора,
  журнал входов и административных действий.

## Нагрузка и ограничения

Базовая версия: 6 источников, обновление раз в секунду, интерполяция карты до
15 кадров/с, один worker и SQLite. Для неё не нужны GPU, Docker или большие
модельные файлы. PBKDF2 вычисляется при входе/создании аккаунта, а не при каждом
обновлении карты. История на диске растёт при длительной работе.

Предпочтительный сервер для общего показа — Ryzen 7/32 ГБ; пригодность обоих
целевых ноутбуков подтверждается отдельным замером. Общая приёмка с ML/ИИ,
доверенным удалённым TLS и на этих устройствах **NOT RUN** до отдельного отчёта.
Запуск с другого устройства требует HTTPS либо заранее проверенного защищённого
туннеля; обычный удалённый HTTP блокируется. [Подробности](docs/AUTH_SECURITY_V5.md).

# Hackathon — автономный шаблон админ-панели

Отдельный интерфейс на HTML, CSS и JavaScript. В репозитории нет кода ProjectVPN, базы данных, Telegram-бота или других сервисов. По умолчанию панель работает с демонстрационными данными в браузере: обзор, разделы, поиск, страницы таблиц, добавление, редактирование и удаление.

## Запуск на Windows через Docker

```powershell
git clone https://github.com/Military05/Hackathon.git
cd Hackathon
docker compose up -d --build
```

Откройте <http://127.0.0.1:8088>. Остановить: `docker compose down`. Docker хранит **только статические файлы**; демонстрационные записи сохраняются в `localStorage` этого браузера. Кнопка «Сбросить демоданные» находится в «Обзоре».

Если установлен Node.js, Docker не нужен: `npm start`, адрес тот же. У проекта нет npm-зависимостей. Для проверки: `npm test`.

## Встроить в другой проект

1. Скопируйте `index.html` и папку `assets/` в каталог статических файлов проекта, например `public/admin/`. Откройте `/admin/`. Ссылки на CSS и JS относительные, поэтому путь можно изменить.
2. В `assets/config.js` задайте название, разделы и поля. `id` раздела — уникальное имя латиницей, а `fields` одновременно определяют таблицу и форму. Поле `table: true` показывает колонку; `required: true` делает поле обязательным. Для выбора укажите `type: "select"` и `options`.
3. Пока серверного API нет, оставьте `mode: "demo"`. Данные хранятся только в браузере и подходят для прототипа.
4. Для настоящих данных установите `mode: "api"`, укажите `api.baseUrl` и `api.resources`. Готовый адаптер использует `GET/POST /resource`, `PUT/DELETE /resource/{id}`. Список должен быть массивом JSON либо объектом `{ "items": [...] }`; каждый объект имеет поле `id`. Маршруты и формат легко заменить собственным адаптером в `assets/main.js` с методами `list(section)`, `create(section, value)`, `update(section, id, value)`, `remove(section, id)`.
5. Доступ к API защищает **ваш сервер**. В шаблоне нет фиктивного логина или секретов в коде. Для сессионного API запросы к тому же домену уже передают cookie; для другого способа авторизации используйте `api.headers` из вашего механизма входа. При размещении API на другом домене настройте CORS на сервере.

Пример настройки нового раздела в `config.sections`:

```js
{
  id: "fields",
  label: "Поля",
  singular: "поле",
  icon: "▦",
  description: "Сельскохозяйственные участки",
  fields: [
    { key: "name", label: "Название", type: "text", required: true, table: true },
    { key: "area", label: "Площадь, га", type: "number", table: true },
    { key: "crop", label: "Культура", type: "text", table: true },
  ],
}
```

Добавьте `fields: "/fields"` в `api.resources`, если используете REST API. В деморежиме новый раздел сразу появится пустым; демонстрационные записи для него можно добавить в `sampleData` в `assets/demo-adapter.js`.

## Что входит в шаблон

| Файл | Назначение |
| --- | --- |
| `index.html`, `assets/styles.css` | Разметка и адаптивное оформление |
| `assets/config.js` | Название, разделы и поля |
| `assets/main.js` | Навигация, таблицы, формы и обзор |
| `assets/demo-adapter.js` | Локальные демоданные без сервера |
| `assets/rest-adapter.js` | Подключение к обычному REST API |
| `Dockerfile`, `compose.yaml` | Самостоятельный запуск на порту 8088 |

`ProjectVPN` живёт в своём репозитории; этот шаблон не изменяет его и не требует запускать его контейнеры. Порт 8088 выбран отдельно от порта 8080 ProjectVPN.

## Рабочие места продукта

| Профиль | Область | Особенность |
| --- | --- | --- |
| dispatcher-1 | logistics: склады, погрузка, подъезды | крупная карта складского сектора |
| dispatcher-2 | production: цеха и внутренние проезды | крупная карта производства |
| dispatcher-3 | coordination: КПП, офис, общие дороги | общая сводка, неизвестное место, помощь и эскалации |

Одна база и один сервер; три окна браузера или три компьютера в локальной сети. Это demo-профили без аккаунтов, паролей, смен и сложных прав. Выбор профиля не является аутентификацией.

Датчики → правила → тревоги работают автоматически. Открытие карточки — просмотр уже обнаруженного случая. ИИ вызывается отдельно и не задерживает обнаружение, маршрутизацию или реакцию людей. Одно продолжающееся нарушение — один Incident; разные нарушения видны одновременно. Не делаем прогноз столкновений, рацию и управление машинами/воротами.

## Начать сейчас

Владелец приглашает участников: Settings → Collaborators → Add people. Каждый принимает приглашение, открывает PowerShell и клонирует проект в свою папку; крупные веса на машине владельца — на E:.

```powershell
git clone https://github.com/Military05/Hackathon.git
cd Hackathon
git status
```

Читаем START_HERE и свою роль. Егор С. фиксирует site.json и контракт v2; Гаджи сразу проверяет API и настоящий вызов инструмента уже скачанной Local-модели. Передача/эскалация входят в обязательную beta-2, а не в список «если останется время».

После проверенной beta-1 одновременно: пара A делает beta-2 с координацией, пара B добавляет ML/агента в feature/beta1-f1, Лия проверяет фиксированный beta-1. Затем main включается в ветку функции, проверяется совместный SHA и один выбранный человек выполняет итоговое объединение.

[Старый QA-runner](docs/QA_AUTORUN.md) покрывает шесть прежних кейсов и не доказывает D5–D10. [Старый HTML-макет](docs/ui/README.md) показывает только идею панелей; не подтверждает три рабочих места или живой ИИ.

**Выбрано задание №3.** Команда: один QA, разработчик бэкэнда, разработчик фронтэнда и два full-stack. План на два дня: 7–8 октября 2026, время Москвы; точные часы сверяем с регламентом.

## Работа двух пар и QA

Пара основы создаёт рабочий скелет → короткая проверка → тег beta-1.

После этого одновременно:

- пара основы улучшает main до beta-2;
- два full-stack в feature/beta1-f1 добавляют интеллектуальный анализ;
- QA проверяет основные функции фиксированного снимка beta-1.

Затем main включается в ветку функции, QA проверяет совместный SHA, итоговый PR попадает в main. Все помогают с интеграцией; одно конкретное слияние выполняет один выбранный оператор.

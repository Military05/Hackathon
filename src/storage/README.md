# Хранение

Здесь чтение/запись данных, если требуется заданием: память, файл или база. Не выбирайте технологию заранее. Формат и сохранность после перезапуска фиксируйте в [контракте](../../docs/CONTRACTS.md).

Не коммитьте реальные секреты и личные данные. Общие маленькие тестовые примеры — в tests/fixtures, личные данные — в игнорируемой data/local. Код пока не реализован.

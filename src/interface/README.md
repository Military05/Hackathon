# Интерфейс

Здесь будущий ввод/вывод: CLI-меню/команды, веб, desktop или другой формат по заданию. Интерфейс вызывает ядро по [контракту](../../docs/CONTRACTS.md), показывает результат и ошибки. Владелец: разработчик интерфейса.

Тема и язык ещё не выбраны. Точка входа будет определена после задания; не создавайте обязательный сервер ради структуры папок.

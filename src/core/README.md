# Ядро

Здесь будущие правила, алгоритмы и основные сценарии. Вход/выход согласуется в [контракте](../../docs/CONTRACTS.md). Для обычного вызова модуль не требует интерактивного ввода или отрисовки. Владелец: разработчик ядра, с просмотром потребителей.

Тема и язык ещё не выбраны. Реального кода пока нет. После задания используйте стандартную структуру выбранного языка.

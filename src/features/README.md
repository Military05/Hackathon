# Дополнительные функции

Здесь будущие расширения пары full-stack. Каждый участник может делать логику, интерфейс и тесты своего сценария. Перед параллельными правками согласуйте владельца общих файлов и [контракт](../../docs/CONTRACTS.md).

После готовности beta-1 пара создаёт общую ветку feature/beta1-f1. Личные PR идут в неё; итоговый PR — в main после совместной проверки. Код пока не реализован.

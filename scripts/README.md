# Служебные команды

Здесь будущие команды запуска, сборки, подготовки данных и проверки, если они нужны выбранному стеку. Сейчас исполняемых скриптов нет. Не делайте обязательным Docker или любой конкретный runtime до выбора задания.

Каждая добавленная команда описывается в [docs/TEAM.md](../docs/TEAM.md) и проверяется другим участником с чистого клона.

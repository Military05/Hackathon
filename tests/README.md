# Проверки

Здесь будущие проверки поведения под выбранный стек. Реальных тестов пока нет. План и журнал: [docs/TESTING.md](../docs/TESTING.md).

Автор проверяет свою задачу до PR; QA независимо проверяет основные функции beta-1 одновременно с разработкой обеих пар, затем совместную версию. Каждая запись результата содержит SHA. Команды тестов после реализации записываются в docs/TEAM.md.

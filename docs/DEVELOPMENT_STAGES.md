# Основные этапы и границы текущей поставки

7 октября 2026. Координатор поручил продолжить только задачи Егора С. и Егора М.
ML, генератор сценариев и локальный агент выполняются другим агентом/контроллером.
Общий контракт v2 с дополнениями PREBUILD_FIXES сохраняется.

## Этап 1 — сервер и SQLite / Егор С.

Поставка: FastAPI, site.json, события/валидация/идемпотентность, правила доступа и
зон, свежесть позиции, отсутствие первого сигнала и потеря связи; атомарный claim,
передача с подтверждением/отменой/истечением, presence ready/away, резерв владельца,
напоминания, эскалация, журнал и курсоры уведомлений. Данные сохраняются в SQLite.

Проверка: tests/runtime/test_backend.py и backend regressions используют реальный
API/SQLite и управляемое время. Результаты запуска фиксируются в RELEASE.
Код каждого этапа отправляется в codex/lightweight-enterprise для тестирования.

## Этап 2 — карта и диспетчерские / Егор М.

Поставка: локальный Leaflet CRS.Simple, собственный план предприятия, три профиля,
журнал/карточка/сводка, инструкции реакции и операции диспетчеров. Клиент сохраняет
ввод при polling, отправляет увиденную revision и показывает конфликт 409.
Позиции и unknown отражают серверные данные. Первая история уведомлений без звука.

Проверка: синтаксис JS, Node-тесты поведения, запуск API и визуальный просмотр карты.
Экран показывается в боковой панели. Чужие панели работают только после подключения
соответствующего модуля; пока они честно показывают недоступность.

## Этап 3 — общая ветка и передача команде

Сначала учитываем свежий origin/main, сохраняя уже объединённые изменения.
Проверенный код этапов 1–2 объединяем в main по поручению координатора.
Команда получает команды запуска, статусы и точные границы остальных задач.
GitHub Actions запускает автоматические проверки при push и PR.

Работу в новом клоне начинают с main. В уже изменённой папке сначала сохраняют
свою работу; нельзя применять reset или force push ради обновления.

```powershell
git switch main
git pull --ff-only origin main
git rev-parse HEAD
git switch -c codex/your-small-task
```

## Передача второму исполнителю

Гриша: согласованный site.json, POST /api/events, реальный DemoRunner/Source,
MovementModel и артефакт. Гаджи: AgentManager, make_router, реальный локальный API,
tools/evidence/очередь. Реализация этих файлов не входит в этапы 1–2.

Егор С. оставил точки подключения в main.py. После проверенного PR владельца:

```powershell
$env:DISPATCH_ENABLE_SIMULATOR='1'
$env:DISPATCH_ENABLE_ML='1'
$env:DISPATCH_ENABLE_AGENT='1'
```

Включайте только фактически поставленные и проверенные модули. До этого сервер
принимает реальные demo Event через API; пустая карта транспорта не доказывает
поломку backend. Через 10 секунд без первого сигнала появляются штатные предупреждения
ожидаемых датчиков. Демонстрацию движения нельзя заменять фиктивной анимацией UI.

## Следующий общий gate / Лия

Три одновременных клиента; реальный внешний симулятор; restart и передача; отказ
LLM; D1–D10; offline запуск и замеры на Ryzen 7 8845HS / 32 ГБ / Radeon 780M.
Полный продукт готов после этого gate, а не после публикации одних инструкций.

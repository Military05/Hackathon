# Подключённые MLP и локальный ИИ

MLP Гриши оценивает движение V1/V2/V3 каждые 5 секунд по последним 10 секундам
сохранённых position-событий. Готовые веса `models/movement-v1` загружаются один
раз; сервер не обучает модель. При необычном движении создаётся модельное
подозрение. Запреты зон, отклонения маршрута, пересечения и КПП проверяются
серверными правилами независимо от MLP. Score — не вероятность аварии.

Агент Гаджи использует Qwen3 4B Q4_K_M через локальный API LM Studio/Bionic.
Диспетчер открывает происшествие и нажимает **«Проанализировать ИИ»**. Задание
поступает в общую очередь: одно выполняется, максимум два ожидают. Агент читает
снимок происшествия, историю, допуски и состояние датчиков разрешёнными
инструментами, затем возвращает факты, предположения и рекомендации. В карточке
доступен ход проверки. Агент не управляет оборудованием и не закрывает случаи.
Для краткого ответа выбираются до четырёх проверяемых фактов, одна гипотеза
и до трёх рекомендаций. Финальный JSON имеет запас до 1024 выходных токенов;
общий предел остаётся 60 секунд и три обращения к модели. Обрезанный ответ
не публикуется как успешный анализ.

## Запуск на компьютере сервера

Для текущих весов MLP нужен **Python 3.12**. В корне проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -WithAI
powershell -ExecutionPolicy Bypass -File scripts/start-ai.ps1 -Port 8773
```

Если команда `python` указывает на другую версию, передайте установщику
`-Python "полный путь к Python312/python.exe"`. В LM Studio/Bionic заранее
скачайте `lmstudio-community/Qwen3-4B-GGUF`, файл `Qwen3-4B-Q4_K_M.gguf`.
Это около 2,5 ГБ; на компьютере с заполненным C: храните модель на E:.
Проверенный SHA256:
`d0c2ac093a77c402f2ddc23a64f68b7c70cfef151899b33e3a6066247104ced3`.
Веса Qwen не входят в Git; веса MLP входят. Существующий сервер на выбранном
порту сначала остановите, не запускайте два процесса с одной базой.

Скрипт создаёт `.env` из примера, если файла ещё нет. Правильные переменные:

```dotenv
LOCAL_LLM_PROVIDER=openai_compatible
LOCAL_LLM_BASE_URL=http://127.0.0.1:1234/v1
LOCAL_LLM_MODEL=hackathon-qwen3-4b
DISPATCH_ENABLE_AUTH=1
DISPATCH_ENABLE_ML=1
DISPATCH_ENABLE_AGENT=1
```

Для сохранения существующих аккаунтов укажите в локальном `.env`
`DISPATCH_DB=полный/путь/к/существующей.db`. Базу, пароли и конфигурацию с
секретами в Git не добавляют. Новый clone получает код, а не чужие аккаунты.
Другому ноутбуку достаточно браузера с доступом к тому же защищённому серверу;
отдельная копия Qwen на каждом клиенте не нужна.
AI launcher слушает только `127.0.0.1`: это локальный запуск на серверном
компьютере. Доступ с другого ноутбука настраивается отдельно через доверенный
HTTPS или защищённый туннель по [REMOTE_CLIENT_V6](REMOTE_CLIENT_V6.md).
Команда запуска сама по себе не открывает сервер в локальную сеть или интернет.

Если провайдер уже запущен и настроен в собственном файле, используйте
`scripts/start-ai.ps1 -Port 8773 -EnvFile "путь.env" -SkipModelLoad`.
Этот вариант не загружает Qwen автоматически и использует указанный runtime.

## Проверка в приложении

1. В блоке «Датчики и диагностика» должны появиться «Модель движения: готова»
   и «ИИ: готов к анализу». `/api/health` показывает отдельные статусы.
2. Запустите сценарий нарушения, откройте появившееся происшествие и нажмите
   «Проанализировать ИИ». Дождитесь «Готов» и проверьте факты и рекомендации.
   В «Ходе проверки ИИ» должны быть реальные вызовы разрешённых инструментов.
3. При изменении фактов прежний анализ может получить отметку «УСТАРЕЛ»;
   повторный анализ запускается отдельным нажатием.
4. Если модель недоступна, мониторинг продолжает работать. Связь с каталогом
   моделей проверяется раз в 10 секунд с таймаутом 3 секунды. После возврата
   провайдера кнопка восстанавливается без перезапуска приложения. Такие
   проверки не запускают генерацию текста.

## Нагрузка

MLP выполняется на CPU с ограничением библиотек до двух потоков. Qwen загружается
одна, context 8192, parallel 1; анализ запускается по запросу диспетчера.
Базовый `scripts/start.ps1` сохраняет режим без ИИ. Запуск Qwen на ноутбуках
с 8 ГБ RAM и встроенной графикой требует отдельного замера; общий показ лучше
проводить с моделью на более мощном сервере. Модельные ответы могут ошибаться,
поэтому решения и ответственность остаются у диспетчера.

Метрики и происхождение MLP: [ML_REPORT](ML_REPORT.md). Подробная история
поставки: [AI_MLP_V5](AI_MLP_V5.md). Текущий способ подключения описан здесь;
старые `LOCAL_MODEL_*` не используются.

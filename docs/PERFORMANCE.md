# Ресурсы и обязательные измерения

Целевой ноутбук по предоставленному скриншоту: AMD Ryzen 7 8845HS, 32 ГБ RAM, встроенная Radeon 780M, Windows 11 x64. Текущий компьютер разработки другой: Xeon E5-2666 v3 / RTX 3070. Его результаты нельзя выдавать за результаты ноутбука.

Архитектура: один FastAPI worker, SQLite, локальная плоская Leaflet-карта без GPS/тайлов, три машины, несколько датчиков, три браузерных клиента, небольшая MLP. LLM: один выполняемый анализ, максимум два ожидающих; мониторинг не ждёт модель. Полные серверы ThingsBoard, Home Assistant и Traccar одновременно не разворачиваются.

Размер MLP около 15 КБ относится только к артефакту; зависимости Python и память процесса больше. Память и скорость LLM зависят от фактической модели/runtime. Ускорение встроенной GPU не обещается.

Лия и Гаджи записывают в RELEASE:

- общий SHA, ноутбук, версии, модель/квантование/контекст;
- число клиентов, событий в секунду и длительность;
- RSS сервера и браузеров, CPU, память/нагрев во время анализа;
- задержку API и пути event received → Incident → экран;
- длительность MLP и реального tools-вызова LLM;
- результат холодного запуска без внешнего интернета и отказа LLM;
- повторное переключение сценариев не создаёт дополнительных источников.

Статус проверки на целевом ноутбуке: NOT RUN. Синтетические метрики MLP не подтверждают промышленную точность. Append-only история растёт во время симуляции; работа 48 часов подряд с постоянным размером базы не заявляется. Для показа использовать ограниченные сеансы, сохраняя историю. Реальный долгий мониторинг потребует отдельного решения о хранении и пагинации.

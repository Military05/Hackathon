# Пример панелей предприятия

## Исторический макет — новая цель ещё не реализована здесь

Текущая цель: три рабочих места, routing/ownership/transfer/presence/escalation и общий ИИ по [DISPATCH_OPERATIONS](../DISPATCH_OPERATIONS.md). Этот HTML — прежняя визуальная заготовка, не реализация v2. Финальный интерфейс Егор М. создаёт в src/interface/web.

enterprise-dispatch.html содержит внешние скрипты/иконки с unpkg.com. Для полностью автономного финального показа нужны локальные ресурсы; скачивание одного этого HTML не гарантирует полноценную работу без интернета. Никакая его кнопка не доказывает настоящий анализ модели или конкурентную работу трёх операторов.

Демонстрационная заготовка интерфейса для обсуждения и реализации. Нет подключения к API приложения, датчикам, SQLite или Qwen. Кнопка «Показать пример анализа» отображает заранее написанный текст и не вызывает модель.

## Просмотр

1. Клонируйте репозиторий и перейдите в эту ветку или скачайте файл [enterprise-dispatch.html](enterprise-dispatch.html) через Download raw file.
2. Откройте локальный enterprise-dispatch.html в современном браузере. GitHub показывает исходный код HTML, а не запускает интерфейс.
3. Выберите офис, склад, цех, КПП или дороги. В складе сырья переключите два отдельных происшествия.
4. Нажмите «Показать пример анализа» и посмотрите исходные события и рекомендации.

## Файлы

- enterprise-dispatch.html — самостоятельная версия для открытия в браузере, включая необходимые стили и оболочку.
- enterprise-dispatch.fragment.html — редактируемый исходник панелей. Это фрагмент для предпросмотра; самостоятельная версия экспортирована из него.
- [ENTERPRISE_PANELS_ARCHITECTURE.md](../ENTERPRISE_PANELS_ARCHITECTURE.md) — схема приложения и предлагаемые дополнения контрактов.

Самостоятельная оболочка содержит локальное сохранение выбора. Пример использует вымышленные события и не доказывает работу правил, обучения или агентных инструментов. Подключение к реальному серверу выполняется отдельной задачей в src/interface/web/ по согласованному CONTRACTS.md.

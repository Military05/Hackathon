# Runtime тесты v7

Ветка обновления: `codex/fix-audit-tests`.
Исходная версия: `281e55ed34572448bee81c5c74b69150424652d5`.

Фикстуры используют автоматически созданный единственный `admin / 123456768`
без профиля диспетчера. Проверки CSRF, Origin, HTTPS, Expected-User, PBKDF2,
истечения и отзыва сессий сохранены. Диспетчеры не читают чужие карточки даже
со `scope=all` или поддельным `X-Demo-Operator`.

Удалённое резервное назначение теперь проверяется как запрещённое действие:
оно не меняет владельца, revision, историю или адресованную передачу.
Сохранены отдельные проверки lease, нескольких вкладок и восстановления после
перезапуска. Гонки claim используют два независимых request_id разрешённого
диспетчера; такой тест действительно проверяет SQLite-конкуренцию, а не отказ
пользователю чужого сектора.

Повторный неразобранный эпизод обновляет одну карточку. После закрытия новый
эпизод создаёт новую карточку. Отклонённое подозрение модели скрывается из
рабочего списка, но наблюдения и карточка доступны в полном представлении.
Администраторская очистка общего журнала остаётся отдельной операцией:
её тесты используют только временную базу и сохраняют аккаунты/исходные Events.

`tests/runtime/isolated_app.py` импортирует глобальное приложение с временным
`DISPATCH_DB` ещё до импорта `src.core.main`. Флаги моделей/симулятора при этом
отключены; исходное окружение восстанавливается сразу после импорта. Каждый
TestCase продолжает использовать собственную временную SQLite. Рабочая
`preview-factory-v5.db` не используется.

Команда полного прогона:

```powershell
python -m unittest discover -s tests/runtime -p 'test_*.py' -v
```

По новой просьбе пользователя «быстрее и без тестов» текущий целевой прогон
остановлен. До остановки завершились проверки auth/backend/regressions и первая
проверка product; окончательный полный runtime результат **NOT RUN**.
В промежуточном прогоне обнаружено старое ожидание видимости отклонённой
модельной карточки; оно исправлено согласно v7, повторный прогон не выполнялся.
Эта запись не является доказательством полностью зелёного набора либо
визуальной/аппаратной приёмки.

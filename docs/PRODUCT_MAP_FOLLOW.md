# Сопровождение транспорта и «Мой сектор»

Область поставки: map-view.js, map-view.css, tests/map-view.test.cjs.
Геометрия, маршруты site.json, сервер и внешние ML/ИИ-модули не меняются.

Клик машины на карте и явный выбор транспорта в списке центрируют карту и
сопровождают полученную позицию. Работает любой транспорт с подтверждёнными
координатами, даже без личного маршрута. Выбор другой машины меняет цель.
Ручное перетаскивание/масштабирование, выбор другого объекта или происшествия,
«Мой сектор» и «Весь план» останавливают сопровождение.

Камера использует ту же интерполированную точку, что машина и установленный
датчик. Позиции не создаются клиентом. Рисование ограничено 15 кадрами/с,
кадровый цикл завершается после движения. Обновление на 1 Гц не перезапускает
кадровый цикл или Leaflet-анимацию камеры. При обычном сопровождении перерисовка
границ дорог и подписей не нужна: проверяется только ограниченная сетка.
Настройка уменьшения движения отключает интерполяцию и плавные наведения.
Устаревшие источники не двигают камеру; monitoring_paused останавливает движение.

«Показать на карте» сохраняет начальное наведение на обе машины для collision,
затем сопровождает основную машину. Обновление той же карточки не прекращает
сопровождение. Недостающие координаты не заменяются придуманными точками.

«Мой сектор» при явном нажатии выделяет собственные здания на 3 секунды.
После таймера или ухода к другой области класс удаляется. Чужие здания
сохраняют серый цвет, текущие цвета принадлежности и тревоги не подменяются.
Эффект не мигает бесконечно; при уменьшении движения остаётся статичная рамка.

## Интерфейс для app.js

- selectAsset(id, {follow: true}) — выбирает транспорт/маршрут и сопровождает
  при наличии координат; follow по умолчанию true. Возвращает boolean наличия
  зарегистрированного/полученного объекта. Повтор текущей цели не меняет камеру.
- followAsset(id, {recenter: true}) — включает сопровождение указанной полученной
  машины; recenter по умолчанию true. Возвращает false без координат.
- clearFollow() — прекращает только сопровождение камеры.
- getFollowedAsset() — ID сопровождаемой машины или null.
- focusSector(id, {animate: false, highlight: false}) — highlight по умолчанию
  равен animate; стартовое/повторное наведение не запускает подсветку.
- showIncident(incident) — явное наведение и сопровождение основной машины.
- highlight(incident) — сохраняет follow для той же карточки, очищает при другой.

showAsset должен вызывать selectAsset при явном выборе пользователя.
showBuilding/showSensor должны вызывать clearFollow для выбора из списка;
клики этих объектов на карте делают это сами. Пассивное обновление сведений
об объекте не должно повторно вызывать selectAsset после ручного перемещения.

# Карта и сценарии v7

Карта принимает `operator` и `role`. Администратор видит все объекты по цветам
ответственных: диспетчер 1 — голубой, 2 — зелёный, 3 — фиолетовый. У диспетчера
чужие объекты и маршруты серые. Принадлежность здания остаётся в подсказке;
внутри здания отображается только подходящее по размеру название.
Зоны сохраняют красный запрет и оранжевый индивидуальный допуск.

«Показать на карте» включает сопровождение машины по серверным позициям.
Повторное обновление выбранной карточки его не отменяет. Перетаскивание карты,
изменение масштаба, другой выбор, «Мой сектор» и «Весь план» прекращают сопровождение.
«Весь план» плавно отводит камеру; настройка уменьшения движения учитывается.

Добавлены единичные эпизоды:

- `red-zone`: V1 по существующему подъезду входит в Z6 и возвращается.
- `orange-zone`: V1 входит в Z1 без индивидуального допуска и возвращается.
- `orange-authorized`: V3 имеет допуск Z1; правило личного маршрута работает отдельно.
- `anomaly-oscillation`: три смены направления туда и обратно по проезду.
- `anomaly-wall`: подъезд к стене W4 и повторные попытки продвинуться у её границы.
- `anomaly-erratic`: ускорения, остановки и резкие изменения направления.

Нарушающая часть ограничена по времени, затем продолжаются нормальное движение
и heartbeat. Источники передают реальные demo Events раз в секунду, дополнительных
потоков нет. `demonstration_complete` и `phase` сообщают о завершении эпизода.
Аномальные сценарии дают MLP фактические точки; вывод модели не подменяется
готовой тревогой. `site.json`, веса модели и внешние модули не изменены.

Тесты не запускались по прямому поручению координатора.

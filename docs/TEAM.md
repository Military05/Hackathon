## Координация

main интегратор: предварительно A1. Общая feature ветка: B1. Зависимости и общий entrypoint: A1. UI entrypoint: A2. Один merge выполняет один оператор; все разработчики помогают согласовать свои изменения. Заменяющего интегратора выбрать до beta-1.

Общий чат: сообщить участникам лично. Время сдачи, встречи и freeze: заполнить по регламенту, freeze за 3 часа до сдачи. Не публикуйте приватные телефоны/токены в публичном репозитории.

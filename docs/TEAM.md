## Координация

main интегратор: предварительно Егор С. (A1). Общая feature ветка: Гаджи (B1). Зависимости и общий entrypoint (точка запуска приложения): Егор С. (A1). UI (пользовательский интерфейс) entrypoint: Егор М. (A2). Один merge (объединение веток) выполняет один оператор; все разработчики помогают согласовать свои изменения. Заменяющего интегратора выбрать до beta-1.

Общий чат: сообщить участникам лично. Время сдачи, встречи и freeze (момент прекращения новых функций): заполнить по регламенту, freeze за 3 часа до сдачи. Не публикуйте приватные телефоны/токены в публичном репозитории.

## Решения

| Вопрос | Решение / статус |
| --- | --- |
| Тема | №3, логистическая инфраструктура предприятия |
| Пользователь | диспетчер |
| Данные | условное предприятие, simulator; разрешение организаторов уточнить |
| Основной стек | Python 3.11+, FastAPI, SQLite, HTML/CSS/JS/SVG |
| beta-1 | карта + реальные события/API/БД + правила D1–D3 |
| beta-2 | улучшение основы/UX/устойчивости парой A |
| F1 | обученная MLP D4 и локальный агент |
| ML (машинное обучение) | StandardScaler + MLPClassifier (16,8), movement-v1 |
| LLM кандидат | Ollama qwen3:4b; реальный tool calling (вызов инструментов моделью) на машине пока не проверен |
| Ограничение | один server worker (обработчик задач), один agent job, локальная LLM отдельно |
| Версии пакетов | Егор С. (A1) закрепляет после совместимой установки |
| Что вне объёма | обучение большой LLM, реальное управление устройствами, много агентов |

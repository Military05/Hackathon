# Команда, решения и команды проекта

Руководство: [TEAM_WORKFLOW.md](../TEAM_WORKFLOW.md). Улучшенный процесс: [PROCESS_IMPROVEMENTS.md](../PROCESS_IMPROVEMENTS.md).

## Состав

Каждый участник меняет свою строку через отдельный PR. Обозначения A1/A2/B1/B2/Q — роли, а не закреплённые GitHub-ники.

| Код | Участник / GitHub | Роль | Основная область | Сегодня: доступ / клон / пробный PR |
| --- | --- | --- | --- | --- |
| Q | заполнить | QA | Сценарии, баги, beta-1 и совместная версия | не подтверждено |
| A1 | заполнить | Бэкэнд / ядро | Основа приложения, данные, правила | не подтверждено |
| A2 | заполнить | Фронтэнд / интерфейс | CLI или иной интерфейс, ввод/вывод | не подтверждено |
| B1 | @Military05 | Full-stack №1 | Функция, адаптация; использует Codex по необходимости | не подтверждено |
| B2 | заполнить | Full-stack №2 | Функция, свой законченный сценарий | не подтверждено |

Full-stack участники могут работать и с ядром, и с интерфейсом. Распределение на каждую задачу фиксируется отдельно.

## Операторы и связь

| Решение | Значение |
| --- | --- |
| Руководитель / владелец репозитория | Military05; уточнить имя |
| Интегратор main | предварительно A1; подтвердить перед первой интеграцией |
| Координатор общей ветки функции | предварительно B1; подтвердить |
| Кто заменяет интегратора | выбрать одного из остальных разработчиков |
| Кто ведёт зависимости/lock-файл | выбрать |
| Общий чат и время коротких встреч | заполнить |
| Точное время сдачи и заморозки функций | заполнить по регламенту |

Все участвуют в объединении. Одно слияние одновременно выполняет один выбранный оператор. Не размещайте в этом публичном документе личные телефоны и приватные ссылки, которые не хотите публиковать.

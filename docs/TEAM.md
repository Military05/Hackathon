## Решения

| Вопрос | Решение |
| --- | --- |
| Задание | №3; допустимость симулятора подтвердить у организаторов |
| Стек | Python 3.11+, FastAPI, SQLite, локальный HTML/CSS/JS/SVG |
| Контракт | v2: CONTRACTS и DISPATCH_OPERATIONS — согласованная цель |
| beta-1 | D1–D3, routing, три профиля, atomic claim и основной журнал |
| beta-2 | обязательные transfer/presence/reminder/escalation/summary/звук |
| F1 | обученная MLP D4 + локальный агент; merge с beta-2 для D1–D10 |
| LLM | сначала скачанные Local-модели Bionic; API установленной версии не подтверждён |
| Runtime | LM Studio /v1/chat/completions после проверки; Ollama резерв, облако не требуется |
| Очередь | одна running, до 20 queued, 120 сек ожидания, 60 сек выполнения |
| Операторы | три demo-профиля, одна база, один server worker, атомарные операции |
| Offline | предварительно подготовленные пакеты/веса/артефакты/локальные ресурсы |
| Исключено | аккаунты/смены/сложные права, прогноз столкновений, рация, управление оборудованием |

## Общие файлы

Егор С.: CONTRACTS, DISPATCH_OPERATIONS (правила/API), site.json, requirements, main.py, SQLite schema, config сроков. Егор М.: src/interface/web и общий UI entrypoint. Гаджи: src/agent и модельный конфиг; Гриша: src/ml и src/simulator; Лия: TESTING/QA fixtures и отчёты. Подключение чужого модуля — согласованный маленький PR с владельцем, не одновременная правка main.py.

Один merge выполняет один выбранный человек; окончательное объединение приложения после review/QA. GitHub-ники, регламент/время сдачи и freeze команда заполняет фактическими данными, без личных токенов/телефонов.

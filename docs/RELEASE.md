# Финальный запуск и сдача

Заполняется после реализации. Сейчас нет выбранного стека, приложения, проверенного релиза или финального тега.

## Паспорт результата

| Поле | Значение |
| --- | --- |
| Название решения / тема | заполнить после задания |
| Что решает / для кого | заполнить |
| Репозиторий | https://github.com/Military05/Hackathon |
| Финальный тег | создаётся после проверки; план final-v1 |
| Точный SHA | заполнить после проверки |

| Проверил запуск | имя, дата, окружение |
| Основной сценарий | заполнить |
| Функция F1 | заполнить |

## Инструкция с чистого компьютера/клона

1. Версии инструментов: заполнить конкретно.
2. Клонирование и переключение на финальный тег.
3. Установка зависимостей и сборка, если нужны.
4. Конфигурация: безопасный .env.example, реальные секреты отдельно.
5. Подготовка/сброс демонстрационных данных.
6. Команда запуска.
7. Пример входа или действия пользователя.
8. Ожидаемый вывод/результат.
9. Остановка приложения.
10. Команда проверки.

Если один из пунктов не нужен, явно напишите «не требуется». Команды должны совпадать с TEAM.md и README. Не вписывайте фиктивные команды выбранного ещё несуществующего проекта.

## Финальная приёмка

- [ ] Все обязательные задачи объединены в main.
- [ ] В проверенном объёме нет открытых P0/P1.
- [ ] Основной сценарий и F1 работают вместе.
- [ ] Пустой/неверный ввод обработан по контракту.
- [ ] Все необходимые файлы отслеживаются Git.
- [ ] Нет секретов и личных данных.
- [ ] Команды подтверждены на чистом клоне другим участником.
- [ ] Результат проверки записан с SHA в TESTING.md.
- [ ] Тег поставлен на этот SHA.
- [ ] Формат сдачи соответствует правилам организаторов.
- [ ] Команда может объяснить код и показать демо.

## Что передаём организаторам

Ссылка на репозиторий + точный тег/commit + инструкция запуска. Если требуется бинарник/архив, он должен соответствовать проверенному source SHA; оформите его после сборки и проверки. Сам тег не означает, что бинарник создан.

После final-v1 исправления проходят повторную проверку и получают новый тег final-v2. Старые проверенные теги не двигаем.

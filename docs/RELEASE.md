# Выпуск базового продукта v5

Дата: 7 октября 2026. Область поставки — Егор С./М.: сервер, SQLite, карта,
движение, аккаунты, базовая защита, КПП и диспетчерские операции.
ML, ИИ и расширенный внешний симулятор имеют отдельных владельцев.
[Инструкция запуска и показа](PRODUCT_V5.md) · [Контракты](CONTRACTS.md).

## Объём v5

- Вход/регистрация pending, локальное создание администратора, назначение
  трёх профилей, блокировка и отзыв сессий.
- PBKDF2, серверная сессия/CSRF, полномочия, X-Expected-User для устаревшей
  вкладки, лимит входов, аудит и отдельный ключ HTTP-источника.
- 18 объектов; единые дороги без повторной оси; красная запретная и оранжевые
  зоны по допуску; тонкие секторные контуры без голубой заливки.
- Реальное наведение «Мой сектор», время сигналов, плотная страница,
  сворачиваемые панели и сохранение камеры при обновлениях.
- ACCESS-G1 и подтверждённые проходы, журнал/фильтры/поиск/CSV, один эпизод
  shift: сначала U1/U2/U3, затем транспорт.
- Сводка успешных диспетчерских действий и ограниченный CSV своей истории.

и 6.39 МБ SQLite. Это моментальный замер текущего процесса, не нагрузочный
benchmark и не доказательство скорости на обоих целевых устройствах.

## Обязательная проверка базового пути

- [ ] Чистый запуск, bootstrap администратора в правильной SQLite, обычный вход.
- [ ] Новая регистрация остаётся pending; администратор подтверждает три сектора.
- [ ] Разные аккаунты в разных browser profiles; смена общей cookie не вызывает
  незаметных действий чужим аккаунтом — X-Expected-User возвращает 409.
- [ ] Без сессии 401, не-admin 403, без CSRF/чужой Origin 403; URL/header не
  подменяет операторский профиль, logout/блокировка отзывают сессию.
- [ ] Внешний POST событий защищён source key; встроенное движение работает без него.
- [ ] normal: три машины и шесть свежих источников, нет ложного нарушения.
- [ ] shift: люди 0/3→3/3, транспорт стоит до проверок, затем движется; общий shift_id.
- [ ] Проход U4 без допуска G1, его Incident у КПП, повтор event_id без дубля.
- [ ] Красная Z3 запрещена всем, Z1/Z2 сохраняют допуски; дороги не входят в здания.
- [ ] «Мой сектор» меняет положение и масштаб для всех трёх профилей.
- [ ] Выбор карточки не сдвигает карту, явное «Показать на карте» сдвигает.
- [ ] Двойной claim/revision/idempotency, передача с подтверждением, резерв,
  восстановление условия и история после restart.
- [ ] Поиск/период/направление/допуск КПП, свои действия, CSV 200/1000 и запрет
  scope=all не-администратору; небезопасные формулы экранированы.
- [ ] Узкий экран без горизонтального переполнения, короткие подписи в зданиях,
  новые события не стирают ввод/камеру и не блокируют журнал.

## Следующий общий gate с отдельными владельцами

D4: настоящий ML-артефакт, независимые метрики, достаточность данных и перенос.
Гаджи: настоящий локальный runtime, tools/evidence, очередь/таймаут/отказ модели.
Лия: три клиента, D1–D10, offline internet, целевые ноутбуки, latency с LLM и без,
доверенное удалённое соединение. Unit/mock/CI не являются этим общим gate.
Мониторинг должен продолжать работать при недоступных ML/LLM.

Не обещаем промышленную безопасность, точную численность людей без известного
начального состояния или отсутствие ошибок на любом оборудовании. События
синтетические; команды воротам/транспорту, рация и прогноз столкновений не входят.

## Интеграция

Зафиксировать head main и feature/beta1-f1; один оператор вливает main → F1; QA проверяет этот SHA без изменений. PR F1 → main merge commit. После merge повторный smoke. Если head изменился после QA, повторить затронутую проверку. Не force-push main.

## Короткая защита

Проблема диспетчера → нормальные события → D1–D3 → D4 и реальные метрики → агент запрашивает историю/допуски → объяснение с evidence → выключение LLM при работающем мониторинге. Отдельно ограничения: demo данные, нет промышленного пилота, score не вероятность аварии.

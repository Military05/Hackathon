# Логистическая сеть и предприятия

Внешняя географическая карта дополняет существующий заводской интерфейс.
Данные учебные; физическое управление транспортом и реальные GPS/сканеры не подключены.
Существующие MLP и Qwen работают с прежними внутренними событиями: географические
координаты не передаются модели как заводские координаты 0..100.

## Основа

MapLibre GL JS 5.6.2 поставлен локально, BSD-3-Clause:
https://github.com/maplibre/maplibre-gl-js. Лицензия: vendor/maplibre/LICENSE.txt.
Подложка OpenFreeMap: https://openfreemap.org/quick_start/. Атрибуция сохранена.
Грузовые маршруты рассчитывает публичный Valhalla https://valhalla.openstreetmap.de/.
Для постоянного опубликованного сервиса нужен свой региональный маршрутизатор
или согласованный провайдер. Публичное демо не гарантирует SLA.
Fleetbase, Traccar и SUMO не установлены: это альтернативные/последующие интеграции.

## Управление

После обычного входа открывается «Логистическая сеть». Выберите сценарий и запустите.
Можно менять скорость учебного времени, ставить паузу и продолжать. Выбор фуры
включает сопровождение; ручное перемещение карты отключает его.
Нажмите площадку и «Открыть предприятие». Отдельные запасы, доки, очередь и рейсы
показаны в контексте этой площадки. Внутренний план — общий шаблон: независимые
комплекты заводских датчиков для каждого внешнего склада пока не создаются.

Склад и перекрытие добавляются по точке на карте. Новый рейс назначается в форме.
При перекрытии требуется объезд от текущего положения; отсутствие допустимого
маршрута или недоступность провайдера не выдаётся за успешный объезд.
Погрузка/разгрузка изменяет учебные запасы при завершении соответствующей операции.

## Контракты

Новый API /api/logistics/* хранит отдельные географические состояния, рейсы и журнал.
Существующие Event/Incident контракты не изменены. Ограниченный снимок логистики
сохраняется в SQLite рядом с аккаунтами. Один сервер двигает машины для всех
клиентов; браузер интерполирует отображение. Управление — администратор/диспетчер 1;
обработка происшествий — диспетчер 1. Сессии, CSRF и проверка пользователя сохранены.

Карта и построение новых маршрутов требуют интернета. Загрузка дорожных данных
всей планеты или тяжёлого физического движка не выполняется.
Тесты, синтаксические проверки и проверочные запросы не запускались по прямой
просьбе пользователя. Новую функциональность нужно принять вручную.

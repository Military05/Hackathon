Подготовка не объединена с main и не применена к работающим серверам.

## Изменения

| Файлы | Поведение |
| --- | --- |
| `src/core/launch.py` | Общий launcher для прежнего приложения; AI требует абсолютную существующую базу с активным администратором, выбирает явный DISPATCH_DB до dotenv; check-only не запускает сервер; auth включена, один worker, proxy headers выключены |
| `scripts/start.ps1` | WithAI, Database, PythonExecutable; запрет занятого порта; проверка Python 3.12/зависимостей и базы до подготовки Qwen; прежние TLS/LAN ограничения сохранены |
| `scripts/start-ai.ps1`, `src/agent/launch.py` | Совместимые входы в общий launcher, порт 8000; отдельного приложения/базы нет |
| `scripts/setup.ps1` | Опциональные AI-зависимости на Python 3.12; основной режим остаётся лёгким |
| `src/agent/runtime.py` | Повторная проверка провайдера раз в 5 секунд и корректное завершение задачи проверки |
| `src/agent/loop.py` | Если провайдер пропустил обязательный get_incident, ограниченный повтор в том же бюджете; непрочитанные факты не принимаются |
| `src/interface/web/app.js` | Анализ доступен только при явном статусе ready |
| `scripts/ai_prepare_check.py` | Проверка только на отдельной копии backup; сопоставление файлов, SHA, таблиц аккаунтов/сессий/истории и реальный CPU inference |
| `tests/runtime/test_launch.py`, `tests/agent/test_runtime.py` | Проверки сохранения выбора базы, отказа пустой/относительной базе, безопасности LAN, check-only, восстановления провайдера и обязательных tools |
| `README.md`, `docs/AI_SERVER_LAUNCH.md`, этот отчёт | Команды, ограничения и план согласованного переключения |

Backend, storage, auth, Event JSON, карта и артефакты MLP в этой ветке не изменены.
Девять проверенных ключевых файлов побайтово совпадают с основной копией,
включая auth, service, operations, demo traffic, storage, карту и веса/metadata.

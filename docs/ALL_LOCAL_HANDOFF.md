# Объединение оставшейся локальной работы

Ветка подготовки: `codex/all-local-release`.
Исходный main: `ba9e606a7734cf2bfb5bb1c84f49174cec15610a`.

Проверены локальные worktree и опубликованные ветки. Основные AI/ML-разработки,
обученная movement-v2, сценарии, интерфейс и проверка доказательств уже включены
в main. Незакоммиченного исходного кода в чужих checkout не обнаружено.
Единственный незакоммиченный файл старого checkout — временное описание PR;
это не часть приложения и оно не изменялось.

Истории `codex/ai-transfer`, `codex/fix-ci-runtime-dependencies` и
`origin/core/demo-simulator` отмечены объединёнными с сохранением текущего дерева
main. Это намеренные history-only merge: начальные standalone API и старая схема
агента уже заменены интегрированными модулями, а CI patch уже включён cherry-pick.
Все старые исходные модули AI остаются в main в текущей редакции; устаревшие
варианты не подменяют актуальный runtime, авторизацию и ограничения.
Два ранних документа AI сохранены отдельно в `docs/archive` с пометкой.

Ранее оставшиеся только на ноутбуке скрипты диагностики, резервного копирования,
защищённого переключения и запуска опубликованы в переносимом виде в `scripts`.
Добавлена установка ярлыка. Описание: [DEVICE_LAUNCH](DEVICE_LAUNCH.md).

Не загружаются рабочие SQLite, резервные копии, `.env`, защищённое окружение,
журналы и локальные отчёты. Это пользовательские данные, не исходный код.
Веса MLP и их метаданные уже находятся в main. Файлы Qwen принадлежат локальной
установке LM Studio; Git не содержит её установленный кэш моделей.

Эта передача не меняет текущий процесс сервера и рабочую базу. Скрипты подготовлены
и проверены отдельно; их исполнение требует явно выбранной существующей базы.

# Контур: краткое описание

Учебный мониторинг автомобильного завода: карта, транспорт, датчики, происшествия
и проходы людей. FastAPI проверяет сохранённые Events, SQLite хранит историю.
Данные демонстрационные; система не управляет реальным оборудованием.

**Роли:** диспетчер 1 — логистика/склады, 2 — производство, 3 — КПП/офис.
Единственный admin / 123456768 создаётся автоматически, управляет доступом и видит
получателей происшествий, но не обрабатывает их. Заявки требуют подтверждения.

**Рабочее место:** отдельные вкладки людей и транспорта/объектов с фильтрами и
сортировкой. Только свои случаи и адресованные передачи; обработанные скрыты.
Очистка карточек сохраняет исходные данные для MLP. Эскалация отключена.

**Карта:** 18 зданий, единая дорожная сеть, персональные маршруты и пешеходные пути.
Красные зоны запрещают движение, оранжевые требуют допуска. Свой сектор цветной,
чужие объекты серые; admin видит три цвета. После «Показать на карте» выбранный
транспорт сопровождается камерой. Ответственные за здания указаны в подсказках.

**Контроль:** въезд без допуска, проход человека без допуска, потеря связи,
отклонение маршрута, сближение транспорта и модельные подозрения. Диагностика
датчиков ручная и периодическая; история доступна серверу и MLP, не загромождает
дашборд. Звук убран. Журналы экспортируются в CSV с русскими колонками и именами.

**Демонстрация:** общие ограниченные эпизоды, включая въезд в зоны и три вида
аномального движения. Смена сначала подтверждает проходы людей, затем транспорт.

**ИИ:** MLP движения и локальный Qwen3 4B подключены отдельным launcher. Модельные
подозрения не подтверждают аварию, возможны ложные срабатывания. Агент читает
сохранённые факты и рекомендует действия; решение принимает диспетчер.

**Другая установка:** исходники с GitHub → установка → запуск → вход admin.
Общие диспетчеры/журналы доступны через один сервер; Git не копирует рабочую базу.
Базовый режим без GPU, один worker, источник 1 Гц и карта до 15 кадров/с.

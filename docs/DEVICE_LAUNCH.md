# Запуск обновлённой версии на Windows

Скрипты, ранее подготовленные локально для переключения «Контур», теперь доступны
в Git. Они не содержат путь личного ноутбука, рабочую базу, ключи или пароли.
Нужны Windows, Python 3.12 с `requirements-ai-dev.txt`, существующая база
с аккаунтами и загруженный Qwen в LM Studio. Для доступа к защищённой базе
и остановки сервера администратора PowerShell тоже должен быть повышенным.

```powershell
# Подставьте свой абсолютный путь к существующей базе.
.\scripts\start-device.ps1 -Database 'C:\ContourData\dispatch.db'

# Принудительно переключить работающий сервер на этот checkout.
.\scripts\restart-device.ps1 -Database 'C:\ContourData\dispatch.db'

# Создать ярлык на рабочем столе с запросом UAC.
.\scripts\install-device-shortcut.ps1 -Database 'C:\ContourData\dispatch.db'

# Только прочитать последние сохранённые задания ИИ.
python scripts/diagnose_ai_readonly.py --database 'C:\ContourData\dispatch.db'
```

Если `.venv` находится в другом checkout, передайте `-PythonExecutable` с её
абсолютным путём. Можно передать `-Checkout` скриптам запуска. Все пути с пробелами
нужно заключать в кавычки. Скрипты не создают пустую базу и не меняют её путь.
Официальный сервер запускается на `127.0.0.1:8000`, одним worker.

`restart-device.ps1` определяет настоящий PID порта, проверяет команду процесса
и его DISPATCH_DB, отклоняет чужую базу. Затем создаёт копию через SQLite
`Connection.backup()` в `%USERPROFILE%\ContourBackups`, проверяет `quick_check`
и администратора. Не останавливает сервер при незавершённом анализе ИИ.
Только после подготовки выключает старый процесс и запускает новую копию.
Проверяет неизменность аккаунтов, сохранность истории, auth, MLP, worker Qwen
и точное соответствие отдаваемого JavaScript текущему checkout.
При сбое пытается вернуть предыдущий код с той же базой; поверх базы ничего
не восстанавливает. Ярлык открывает панель только после подтверждения готовности.

Окружение предыдущего процесса хранится под Windows DPAPI. Это сохраняет ключ
источников и настройки локального провайдера без печати секретов. Файл находится
в игнорируемой `data/local/diagnostics`; он привязан к пользователю Windows
и не предназначен для переноса на другой ноутбук или загрузки в Git.
Отчёты содержат числа записей и контрольную сумму аккаунтов, а не пароли.

`start-device.ps1` при отсутствии сервера делает проверенную копию и запускает
приложение. Если нужная версия уже готова, просто открывает её. Проверка JavaScript
сравнивает байты UTF-8, чтобы особенности кодировки PowerShell не давали ложное
сообщение о старом интерфейсе.

Автоматические тесты подготовки работают только с временными SQLite-базами.
Linux CI пропускает один тест DPAPI; остальные проверки резервного копирования
и неизменности исходных записей выполняются. Настоящее переключение процессов
Windows не выполняется в CI. Готовность health не является тестом ответа Qwen
или замером RTX 4060.

# Показ и проверка автомобильного завода v6

Версия 8 октября 2026, базовая область Егора С./М. MLP и локальный ИИ теперь
интегрированы отдельной поставкой владельцев в main; включаются отдельным запуском.
Запуск и создание администратора — [README](../README.md), регистрация и
подтверждение трёх диспетчеров — [PRODUCT_V5](PRODUCT_V5.md).
Один сервер/SQLite хранит общие аккаунты, события и действия всех клиентов.

## Карта и управление

18 зданий имеют подъезды к единой дорожной сети. Пять пунктирных путей обозначают
пешеходные связи: сами линии не генерируют проходы и не считают людей.
КПП фиксирует подтверждённые Event от ACCESS-G1. Пять красных зон Z3–Z7
запрещают весь транспорт либо конкретный тип; наведите мышь на зону для её правила.
Оранжевые Z1/Z2 работают по индивидуальному допуску, голубой заливки нет.

Галочка «Маршруты» показывает личные пути V1/V2/V3. Нажмите машину, чтобы
выделить её путь и прочитать назначение, запреты и свежесть позиции.
«Мой сектор» плавно наводит камеру на область назначенного сервером диспетчера;
при системном уменьшении движения наведение происходит сразу. Обновление данных
не сбрасывает камеру. «Весь план» возвращает обзор.

«На смене» сообщает готовность диспетчера принимать работу. Снятие галочки
публикует away и участвует в существующей логике резерва/переназначения.
Это не декоративная кнопка и не завершение браузерной сессии.

## Сценарии для жюри

Откройте «Движение и сценарии» над происшествиями, выберите сценарий и нажмите
«Запустить сценарий». Он общий для всех рабочих мест. Под выбором показан
ожидаемый результат; это описание, а не готовая тревога. Сервер действительно
генерирует position/access/heartbeat и проверяет полученные события.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Обычная работа завода | Три личных маршрута, без новых нарушений |
| Доставка сырья и отгрузка | Движение и остановки складского транспорта |
| Смена персонала | U1/U2/U3 проходят КПП; после 3/3 начинается транспорт |
| Объезд технической службы | Штатный служебный маршрут |
| Въезд в закрытую зону | Въезд без допуска, затем восстановление после выхода |
| Проход без допуска | Подтверждённый проход U4, карточка у диспетчера КПП |
| Потеря связи с датчиком | HB-QA молчит с 5-й по 17-ю секунду, затем возвращается |
| Несколько одновременных происшествий | Зона, проход, потеря сигнала и отклонение маршрута |
| Отклонение транспорта от маршрута | V1 уходит с личного пути, две точки подтверждают нарушение |
| Пересечение транспорта на проезде | V1/V3 сближаются, карточка содержит обе машины и события |
| Безопасный разъезд транспорта | Нового пересечения быть не должно |
| Погрузчик в производственной зоне | V2 попадает в Z5, запрещённую его типу |
| Служебный транспорт в закрытой зоне | V3 попадает в Z4, затем возвращается на путь |

Для нарушающих сценариев подождите до 45 секунд: некоторые сначала показывают
подъезд к зоне. После завершения заданного пути транспорт продолжает штатный
маршрут. Сценарии не удаляют старые карточки/журналы. Для нового результата
сравнивайте время обнаружения и фильтруйте тип. Отклонение может сопровождать
въезд в зону или пересечение — это два разных наблюдаемых условия.

Диспетчер 1 — логистика/склады, 2 — производство, 3 — КПП/координация.
Случай назначается по месту, а не названию сценария; резерв/передачи сохранены.
Откройте карточку → «Показать на карте» → «Принять ответственность» → запишите
реакцию → после восстановления «Завершить». При активном/неизвестном условии
сервер не разрешит завершение. В парном случае подсвечиваются обе машины.

## Что означают новые правила

route_deviation: расстояние до личной ломаной safety_routes больше 2 условных
единиц; две свежие точки вне пути создают предупреждение, две внутри восстанавливают.
collision: свежие измеренные положения и близкие по времени отрезки движения
сближаются до суммы радиусов машин (по умолчанию 0.5 + 0.5 единицы).
Проверяется общий интервал времени, а не геометрическое пересечение любых дорог.
Восстановление требует двух свежих разделений; устаревание даёт unknown.
Повтор одного Event не создаёт повторную тревогу.

Это условные координаты 0–100, не метры. Между соседними показаниями симуляция
предполагает прямое движение. Карточка показывает наблюдаемое пересечение,
не подтверждает физическое ДТП и не прогнозирует аварию. Клиентская плавная
анимация не является источником доказательств. ML для этих правил не нужен.

## CSV и перенос на другой ноутбук

«Скачать журнал КПП» сохраняет Журнал_проходов_КПП_дата.csv;
«Скачать журнал действий» — Журнал_действий_диспетчера_дата.csv.
Внутри русские колонки/значения, UTF-8 BOM, разделитель `;`, время МСК с секундами
для аудита. КПП — до 200 последних строк с текущими фильтрами; действия — 1000
по умолчанию, максимум API 2000. Строки, похожие на Excel-формулы, экранируются.
Если Excel не разделил колонки: «Данные → Из текста/CSV», кодировка UTF-8,
разделитель «точка с запятой». JSON API остаётся с техническими именами полей.

Чтобы пользоваться теми же паролями с другого устройства, открывайте тот же
сервер через доверенный HTTPS/защищённый туннель. Fresh clone создаёт собственную
базу, а не копирует аккаунты. [REMOTE_CLIENT_V6](REMOTE_CLIENT_V6.md).
Пароли, SQLite, приватные ключи и модельные веса не публикуются в Git.

## Мощность и ограниченные проверки

Один Python worker, SQLite, шесть источников при 1 Гц, ограниченная интерполяция
карты до 15 кадров/с. Для трёх машин проверяются только три пары; WebGL/GPU,
Docker, сервер карты и LLM базовому пути не требуются. Целевые ноутбуки и реальный
удалённый TLS ещё требуют отдельной приёмки Лии; новая карта не является benchmark.

В этом выпуске выполняются только затронутые проверки: правила транспорта,
геометрия/карта, интерфейс/CSV и короткий живой показ. Подробный отчёт —
[RELEASE](RELEASE.md). Базовый запуск оставляет ML/ИИ выключенными.
Текущая интеграция и её ограничения — [AI_MLP_V5](AI_MLP_V5.md);
исторический порядок передачи — [AI_INTEGRATION_V6](AI_INTEGRATION_V6.md).
